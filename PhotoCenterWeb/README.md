PhotoCenterWeb
Веб-приложение для управления фотоцентром: клиентская часть на React, серверная — на ASP.NET MVC 5 + Web API 2 с базой данных MariaDB. Включает в себя: авторизацию через JWT, REST API, работу с ORM Entity Framework 6, админ-панель и генерацию PDF-отчётов на клиенте.

_______________ Стек технологий _______________

Backend
- .NET Framework 4.7.2
- ASP.NET MVC 5 — отдача SPA и статических файлов
- ASP.NET Web API 2 — REST API для React
- Entity Framework 6 — ORM, доступ к БД
- MariaDB — СУБД
- BCrypt.Net — хеширование паролей
- JWT (HMAC-SHA256) — аутентификация и авторизация по ролям

Frontend
- React 19 — UI
- React Router 7 — маршрутизация SPA
- Vite — сборка бандла
- html2canvas + jsPDF — генерация PDF-отчётов на клиенте

Инфраструктура
- IIS Express
- NuGet — управление пакетами .NET
- npm — управление пакетами JS

_______________ Функциональность _______________
Аутентификация
- Вход по логину и паролю
- JWT-токен с временем жизни 120 минут
- Роли: Client, Employee, Admin

Админ-панель. Доступ только для роли Admin. Включает в себя:
- Пользователи — редактирование логина, имени, роли, статуса; создание новых
- Заказы — назначение исполнителя, изменение статуса, суммы, даты
- Аналитика — заказы по статусам, выручка по месяцам, топ услуг
- Удаление — пользователей и заказов по ID
- Отчёт — генерация PDF с выбранными разделами
